# methuselah
gpg and git credential helper

### Dependencies
```sh
# For debian-based
apt install \
  libgpg-error-dev \
  libassuan-dev \
  libxrandr-dev \
  libxinerama-dev \
  libxcursor-dev \
  libxi-dev

# For Artix/Arch
pacman -Syy \
  base-devel \
  meson \
  cmake \
  pkgconfig \
  git \
  alsa-lib \
  mesa \
  gpgme \
  libxi \
  libassuan \
  xorg-xrandr \
  libxinerama \
  libxcursor
```
